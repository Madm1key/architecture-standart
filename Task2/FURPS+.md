| F   | Функциональные (Functionality)                                                                                                    |                                                                                                                |

| F2  | Клиент может оставить заявку на депозит на сайте.                                                                                 |                                                                                                                |

| U1  | Соответствие дизайн-системе.                                                                                                      |                                                                                                                |
| R   | Надёжность (Reliability)                                                                                                          |                                                                                                                |
| R1  | Доступность 24/7.                                                                                                                 |                                                                                                                |
| R2  | SLA 99.9%.                                                                                                                        |                                                                                                                |
| R3  | Доступно переключение на резервный ЦОД.                                                                                           |                                                                                                                |

| P1  | Отклик по всем операциям должен занимать < 1 с.                                                                                   | Сейчас некоторые справочные данные загружаются > 1 с.                                                          |
| P2  | Приложения должны поддерживать горизонтальное масштабирование.                                                                    | Из-за особенности реализации АБС может масштабироваться только вертикально.                                    |

| S3  | Наличие тех. документации для обеспечения дальнейшего расширения системы.                                                         |                                                                                                                |

| +R1 | Требуется шифрование трафика.                                                                                                     |                                                                                                                |
| +R2 | Для реализации асинхронного взаимодействия необходимо использовать Kafka.                                                         | Cтоит учитывать что текущая версия приложения несовместима с ней. Нужен переход на микросервисную архитектуру. |
| +R3 | Необходимо реализовать асин-е взаимодействие АБС и интернет банка.                                                                | БД АБС перегружена.                                                                                            |
